## 1. เป้าหมายการออกแบบ (Design Goals)

กำหนดรูปแบบและระบบการทำงานของเกม EmoRelief AI ให้สามารถพัฒนาเป็นเกมบนมือถือได้จริง โดยเน้นการระบายอารมณ์ผ่านกิจกรรมภายในเกม การประเมินระดับความโกรธก่อนและหลังเล่น และการประยุกต์ใช้ AI FOR THAI API เพื่อสนับสนุนการประมวลผลและให้คำแนะนำตามความสามารถของ API ที่ตรวจสอบแล้ว

**ข้อมูลโครงการ**
- ชื่อโครงการ: EmoRelief AI
- ประเภทเกม: เกมระบายอารมณ์แบบโต้ตอบ (Interactive Emotional Relief Game)
- แพลตฟอร์ม: โทรศัพท์มือถือ (Mobile Application)
- เครื่องมือพัฒนาเกม: Unity (รอทีมยืนยัน 2D หรือ 3D)
- บริการ AI: AI FOR THAI API (รอยืนยันบริการที่เหมาะสม)
- ผู้รับผิดชอบเอกสาร: Role 3

**หลักการออกแบบ**
1. เล่นง่าย ไม่ซับซ้อน
2. ส่งเสริมให้ผู้เล่นตระหนักรู้และเข้าใจอารมณ์ของตนเอง
3. มีกิจกรรมระบายอารมณ์ที่หลากหลาย
4. ประยุกต์ใช้ AI ตามความสามารถของ API ที่มีอยู่จริง
5. คำนึงถึงความปลอดภัยและความเป็นส่วนตัวของผู้เล่น

## 2. แนวคิดของเกม (Game Concept)

EmoRelief AI เป็นเกมระบายอารมณ์แบบโต้ตอบสำหรับผู้เล่นคนเดียวบนโทรศัพท์มือถือ ผู้เล่นสามารถเลือกอารมณ์ของตนเองก่อนเข้าสู่กิจกรรมระบายอารมณ์ภายในเกม

หลังจากเล่นเกมเสร็จ ผู้เล่นจะประเมินระดับความโกรธอีกครั้ง เพื่อเปรียบเทียบความรู้สึกก่อนและหลังเล่น พร้อมรับคำแนะนำในการจัดการอารมณ์

**ลำดับการเล่น**
0. Disclaimer
1. เลือกอารมณ์ที่กำลังรู้สึก
2. ประเมินระดับความโกรธก่อนเล่น (0–10)
3. เลือกกิจกรรมระบายอารมณ์// Build your opponent 
4. เล่นเกม
5. ประเมินระดับความโกรธหลังเล่น (0–10)
6. แสดงผลเปรียบเทียบและคำแนะนำ

**หลักการสำคัญ**
- ผู้เล่นสามารถเลือกใช้ตัวละครสำเร็จรูปได้
- เป้าหมายในเกมต้องเป็นตัวละครสมมติ หุ่นฝึกซ้อม หรือวัตถุจำลอง
- คะแนนความโกรธมาจากการโจมตีในเกม //API
- AI ประเมินตัดสินสุขภาพจิตของผู้เล่น //API
- เกมหลักต้องเล่นได้แม้ AI หรืออินเทอร์เน็ตไม่พร้อมใช้งาน

## 3. ขอบเขตเกมเวอร์ชันแรก (MVP Scope)

**สิ่งที่อยู่ในขอบเขตการพัฒนา**
- ระบบเล่นคนเดียว
- ระบบเลือกอารมณ์ก่อนเล่น
- ระบบประเมินระดับความโกรธ 0–10
- ระบบเลือกอาวุธ 6 รูปแบบ
- ระบบแสดงภาพเคลื่อนไหวและเสียงประกอบ
- ระบบคะแนนและสถานะภายในเกม
- ระบบประเมินระดับความโกรธหลังเล่น //API
- ระบบเปรียบเทียบคะแนนก่อนและหลังเล่น
- ระบบแสดงผลและคำแนะนำ //API
- การเชื่อมต่อ AI FOR THAI API ผ่านระบบหลังบ้าน (Backend) ตามบริการที่เลือกใช้จริง
- รองรับการเล่นเกมแบบไม่เชื่อมต่อ API (Local) เมื่อระบบ AI ไม่พร้อมใช้งาน

**กิจกรรมทั้ง 6 รูปแบบ**

1. **Punch — ต่อยหุ่นฝึกซ้อม**
   - ผู้เล่นใช้หมัดต่อยหุ่นฝึกซ้อม
   - มีภาพเคลื่อนไหวและเสียงประกอบขณะต่อย

2. **Slap — ตบเป้าหมายการ์ตูน**
   - ผู้เล่นกดปุ่มเพื่อให้เกิดภาพเคลื่อนไหวการตบ
   - ใช้ตัวละครหรือเป้าหมายการ์ตูน

3. **Egg Throw — ปาไข่ใส่เป้าหมาย**
   - ผู้เล่นเล็งและปาไข่ไปยังเป้าหมาย
   - มีเอฟเฟกต์ไข่แตกกระจาย

4. **Slingshot — ยิงหนังสติ๊ก**
   - ผู้เล่นดึงหนังสติ๊กและปล่อยเพื่อยิง
   - ใช้ลูกกระสุนจำลอง เช่น ลูกบอลสี ยิงใส่เป้าหมาย

5. **Baseball Bat — ใช้ไม้เบสบอลตีเป้าหมาย**
   - ผู้เล่นเหวี่ยงไม้เบสบอลเพื่อตีเป้าหมาย
   - มีภาพเคลื่อนไหวและเอฟเฟกต์เมื่อถูกเป้าหมาย

6. **Dart Throw — ปาลูกดอก**
   - ผู้เล่นเล็งและปาลูกดอก
   - ใช้กระดานเป้าหมายสำหรับการเล่น

**สิ่งที่ไม่อยู่ในขอบเขตการพัฒนา**
- ระบบผู้เล่นหลายคน (Multiplayer)
- ระบบแข่งขันออนไลน์
- ระบบจัดอันดับ (Leaderboard)
- ระบบสมาชิกและเข้าสู่ระบบผ่านโซเชียล
- การวิเคราะห์อารมณ์แบบเรียลไทม์

## 4. กติกาและระบบคะแนน (Game Mechanics)

ระบบคะแนนแบ่งออกเป็น 2 ประเภท ซึ่งต้องแยกจากกันอย่างชัดเจน

**4.1 คะแนนกิจกรรมภายในเกม (Gameplay Score)**

ใช้แสดงผลการเล่นและความคืบหน้าของกิจกรรม โดยแต่ละกิจกรรมอาจมีวิธีควบคุมและการให้คะแนนแตกต่างกัน

// Attribute to API
- Punch: กดปุ่มเพื่อให้ตัวละครต่อยหุ่นฝึกซ้อม
- Slap: กดปุ่มเพื่อให้เกิดภาพเคลื่อนไหวการตบ
- Egg Throw: เล็งและกดเพื่อปาไข่
- Slingshot: ลากเพื่อดึงหนังสติ๊ก แล้วปล่อยเพื่อยิง
- Baseball Bat: กดหรือปัดตามจังหวะเพื่อเหวี่ยงไม้ตี
- Dart Throw: เล็งทิศทางและปาลูกดอกใส่กระดานเป้าหมาย

**4.2 คะแนนระดับความโกรธ (Anger Level Score)**

เป็นคะแนนที่ผู้เล่นประเมินความรู้สึกของตนเอง ตั้งแต่ 0–10

- 0–2: โกรธน้อยมาก (Very Low)
- 3–4: โกรธเล็กน้อย (Low)
- 5–6: โกรธปานกลาง (Moderate)
- 7–8: โกรธมาก (High)
- 9–10: โกรธมากที่สุด (Very High)

**4.3 การเปรียบเทียบคะแนนก่อนและหลังเล่น**

ตัวอย่าง:
- ก่อนเล่น: 8/10
- หลังเล่น: 4/10
- ผลต่าง: ลดลง 4 คะแนน

สูตรคำนวณ:

คะแนนก่อนเล่น − คะแนนหลังเล่น = ผลต่างของคะแนน

หมายเหตุ: คะแนนที่ลดลงแสดงถึงการประเมินความรู้สึกของผู้เล่นที่ลดลงเท่านั้น ไม่ใช่หลักฐานว่าความเครียดหรือปัญหาสุขภาพจิตได้รับการรักษาแล้ว

## 6. การเชื่อมต่อ AI FOR THAI API

กำหนดให้ AI FOR THAI เป็นบริการ AI ภายนอกที่เชื่อมต่อกับระบบเกมผ่านระบบหลังบ้าน (Backend)

**ขั้นตอนการทำงาน**
1. รับข้อมูลจากผู้เล่น เช่น คะแนนประเมินก่อนและหลังเล่น รวมถึงกิจกรรมที่เลือก
2. ระบบ Backend เตรียมข้อมูลและส่งคำร้องขอไปยัง API ที่เลือกใช้
3. Backend รับและตรวจสอบผลตอบกลับจาก API
4. ส่งผลลัพธ์กลับมายังเกมเพื่อแสดงผลและคำแนะนำ

**รายการที่ต้องตรวจสอบ**
- ตรวจสอบ API ที่เหมาะสมกับโครงการ
- ศึกษาเอกสาร API (API Documentation)
- ตรวจสอบรูปแบบข้อมูลนำเข้าและผลลัพธ์ (Input / Output)
- ทดสอบ API Endpoint
- ตรวจสอบข้อจำกัดการใช้งาน (API Limit)
- ทดสอบการเชื่อมต่อกับ Backend

**ข้อกำหนดสำคัญ**

ขณะนี้ยังไม่ได้ยืนยันว่า AI FOR THAI มี API ที่สามารถวิเคราะห์ความโกรธจากคะแนนตัวเลขหรือพฤติกรรมการเล่นเกมได้โดยตรง หากไม่มีบริการดังกล่าว ต้องแยกการประเมินตนเองออกจากการวิเคราะห์ของ AI และเลือกใช้ความสามารถของ API ที่มีอยู่จริง ห้ามระบุว่า AI วิเคราะห์อารมณ์ได้จนกว่าจะตรวจสอบและทดสอบแล้ว

## 8. ข้อกำหนดการออกแบบหน้าจอ (UI/UX Requirements)

- หน้าแรก: แสดงโลโก้และปุ่มเริ่มเกม
- หน้าเลือกอารมณ์: ให้ผู้เล่นเลือกอารมณ์ที่กำลังรู้สึก
- หน้าประเมินความโกรธ: ใช้แถบเลื่อนคะแนน 0–10
- หน้าเลือกกิจกรรม: แสดงกิจกรรมทั้ง 6 รูปแบบ พร้อมภาพหรือไอคอน
- หน้าเล่นเกม: แสดงภาพเคลื่อนไหว เสียง คะแนน และปุ่มควบคุม
- หน้าประเมินหลังเล่น: ใช้แถบเลื่อนคะแนน 0–10
- หน้าแสดงผล: เปรียบเทียบคะแนนก่อนและหลัง
- หน้าคำแนะนำ: แสดงคำแนะนำในการจัดการอารมณ์

**แนวทางการออกแบบ**
- สีหลัก: ม่วง ชมพูอมม่วง และชมพู (Purple, Magenta, Pink)
- รูปแบบภาพ: การ์ตูนสมัยใหม่ (Modern Cartoon)
- ใช้หุ่นยนต์มาสคอตประจำ EmoRelief AI
- ปุ่มควบคุมต้องเหมาะสมกับหน้าจอโทรศัพท์มือถือ
- ใช้ข้อความและไอคอนที่เข้าใจง่าย
- แยกคะแนน Gameplay Score และ Anger Level Score ให้ชัดเจน
- ใช้เป้าหมายจำลองและเอฟเฟกต์การ์ตูน ไม่ใช้ภาพความรุนแรงสมจริง

- TC-15: กดเล่นอีกครั้ง → ระบบเริ่มรอบใหม่ได้ถูกต้อง

## สรุปโครงการ (Project Summary)

EmoRelief AI เป็นเกมระบายอารมณ์แบบโต้ตอบบนโทรศัพท์มือถือ ที่มุ่งเน้นการส่งเสริมการตระหนักรู้ทางอารมณ์ ผ่านกิจกรรมภายในเกม 6 รูปแบบ ได้แก่ Punch, Slap, Egg Throw, Slingshot, Baseball Bat และ Dart Throw
